# CRR Tool Suite — Architecture Decisions Register (ARCH-MIG-01)

**Purpose:** the durable record of design decisions made during the rules-bundle migration, so they do not live only in chat history, PR descriptions or one session's notes. Companion to `SECURITY_DECISIONS.md` (SD/SR) and `instructions/arch-mig-known-issues.md` (KI).

**How to use this file:**
- Append-only. Supersede, don't rewrite (`Superseded by AD-xx`).
- `AD-xx` = a design decision. Status is one of **Accepted** (in force), **Proposed** (recommended, awaiting the named decider), **Pending clinical ruling** (engineering has encoded one reading; the clinical review pack carries the question).
- A decision that changes bundle content, engine behaviour or what a referrer sees names the slice that implements it and the check that enforces it.
- **Change log:** from AD-12 on, the `Enforced by` cell ends with `Change log: CL-nn` — the row(s) in `documents/CHANGE-LOG.md` that record the user-, operator- or requirement-visible effect of the decision (`none` when the decision changes nothing visible). The AD says *why*; the CL row says *what changed and which documents must reflect it*.
- Both Gary and Claude Code add entries whenever a design call is made. CLAUDE.md points here.

## AD-21 mapping — bundle fields → FHIR CPG IG package

A serialiser from the published bundle to a CPG-conformant ImplementationGuide package is mechanical; this table is the field mapping. **No IG Publisher adoption now** — this exists so the option stays thin future work.

| Bundle field | CPG / IG package element |
|---|---|
| `library.site` (ELM JSON) | `Library` resource, `type = logic-library`, ELM as a `content` attachment (`application/elm+json`); CQL as a second attachment where kept |
| `library.population` (ELM JSON) | a second `Library` (`type = logic-library`), referenced by the site Library |
| `planDefinition` | `PlanDefinition` (`type = eca-rule` / clinical-guideline), `action.condition[].expression` naming Library defines, `action.definitionCanonical` for sub-actions |
| `questionnaire` | `Questionnaire`, SDC-populable items carry `initialExpression`; the national one is `Questionnaire/CRR-National` |
| `overlays[]` | `PlanDefinition` "delivery" overlays or `Library` parameters keyed by region — information only (they carry no logic, per invariant 7) |
| `vocabularyVersion` | the vocabulary `CodeSystem`/`ValueSet` package version; `ImplementationGuide.dependsOn` |
| `source` (`type`, `title`, `identifier`, `date`, `pages`) | `Library.relatedArtifact[].type = derived-from`, `citation` = the published document + page span |
| `logicHash` | `Library.identifier` (a hash-scheme identifier) — build reproducibility |
| `version`, `state` | `Library`/`PlanDefinition` `.version` and `.status` (`draft` → `active` on publish) |
| `testResults` | `TestScript` / test report artefacts referenced from the IG |
| `kind: "national"` | the national layer's `PlanDefinition` + `Library`, applied before site PlanDefinitions |
| `examSite` ↔ published ids (AD-01) | `ImplementationGuide` `resource` entries + a concept map / naming-system for the 53→38 id resolution |
